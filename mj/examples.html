Examples

This page does not contain a hardcoded list of examples. It walks the examples/ directory of the repository, and every subdirectory inside it, then renders whatever it finds. Reload the page, or press the button below, and it runs again.

Listing is tried first through jsdelivr's public GitHub CDN, which has generous rate limits, then falls back to the GitHub API if that fails. One request lists every file under examples/; each file's source is fetched only when you expand it. The listing is cached in your browser for 10 minutes, so ordinary reloads do not repeat the network call -- press "Reload from GitHub" to force a fresh fetch.
