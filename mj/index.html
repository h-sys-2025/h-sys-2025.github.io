mj

An embeddable systems scripting language, written in C for Linux x86-64. A small bytecode VM with a template JIT, computed-goto dispatch, C/C++/Odin interop, and a growing standard library.

Goals: fast, embeddable, biodiverse tooling, minimal side-effect surface in the core. IO is explicit, through natives and the standard library.

Updated 2026-08-17: macro export across imports, a compile-time preprocessor, new array and ref builtins, five C interop plugins, and a fix for catch(err) parsing. See What's new below.

Quick start

./build.sh
./build/mj examples/curriculum/01_values.mj
# or, directly:
gcc -O3 -o build/mj mj.c stdlib/builtins/builtins.c -I. -lm -ldl -lpthread

There is also a small REPL: run ./build/mj with no file. #help, #quit, #clear; expressions auto-print.

An experimental package manager ships alongside the language. A permanent one is planned to be written in mj itself.

./mjpm.sh list
./mjpm.sh init demo && cd demo && ../tools/mjpm.sh add math && ../tools/mjpm.sh run

A short taste

fun loopsum(n) {
  var s = 0;
  var i = 0;
  while (i < n) {
    s = s + i;
    i = i + 1;
  }
  return s;
}
print loopsum(1000);          // 499500

fun min_pair(a: int, b: int): (int, int) {
  if (a < b) { return (a, b); }
  return (b, a);
}
var tp = min_pair(9, 3);
print tp.get(0);              // 3

var a = array();
push(a, 10); push(a, 20); push(a, 30);
print a.get(1);               // 20

var m = map();
m["x"] = 7;
print haskey(m, "x");         // true

print "  hi  ".trim().upper(); // HI

What's new (2026-08-17)

Four commits landed on master on 2026-08-17, summarized here from the diff:

catch(err) parsing fixed

This was listed as a known bug in the README and is now fixed. catch(err) { ... } bodies accept ordinary statements (print, var, and so on), not just a single trailing expression. The last value left on the stack becomes the recovery result. 

var x = 1 / 0 catch(err) {
  print err;
  0;
};
print x;

var y = panic("boom") catch(e) {
  print e;
  99;
};
print y;

A compile-time preprocessor

#define and #macro now export across imports: a macro defined in an imported file becomes visible to the importer. There's also a small set of conditional directives:

DirectiveRole
#define NAME valobject-like macro
#define F(x) ...function-like macro
#undef NAMEremove a macro
#if / #else / #endifcompile-time branch
#ifdef / #ifndefmacro-presence branch
defined(NAME)usable inside #if
$os / $arch"linux" / "x86_64" etc, usable in #if
 
#if $os == "linux"
  print "linux";
#else
  print "other";
#endif

#define VER 2
#ifdef VER
  print VER;
#endif
#undef VER
#ifndef VER
  print "undefined VER";
#endif

stdlib/fs.mj uses this to export short aliases (read, write, ls, cwd, mkdir, and more) alongside the original fs_* functions, so fs.ls(fs.cwd()) now works the same as fs.fs_ls(fs.fs_cwd()).

Five C interop plugins

These live in stdlib/extern_c/ and use the same int64 ABI as native ... from, cimport, and cbind.

PluginCoversExtra link flags
radix_utils.chex / octal / binary parse and formatnone

pcap_lite.clibpcap capture-lpcap, optional
sdl2_plug.cSDL2 window / rendererpkg-config --libs sdl2
raylib_plug.craylib window / drawing-lraylib -lGL ...
The two new example files for these plugins, examples/demo_net.mj and examples/demo_radix.mj, point native ... from at a path that doesn't exist in the repository ("I_like_bj/native_plugs/net_sockets.c"). The plugins are actually at stdlib/extern_c/net_sockets.c and stdlib/extern_c/radix_utils.c -- the same typo appears in stdlib/extern_c/README.md's own build command. Update the path locally before running either example.

Smaller changes

  • Optimizer: two more superinstructions where applicable, OP_ADD_LOCAL_CONST and OP_MUL_LOCAL_CONST, plus SSA-style register hints feeding the template JIT.
  • REPL: expression auto-print now goes through var __repl_v = (...); print __repl_v; instead of a raw statement, which behaves better for expressions with side effects.
  • The -nW (no-warnings) flag was removed from mj.c's argument parser.
  • Import path resolution and import-time error messages were tightened up, per docs/ERRORS.md.
  • docs/OPTIMIZATIONS.md now lists builtins by group, matching the new function table. docs/DISASM.md was replaced with a full disassembly transcript in place of the earlier short snippet.

Design note

mj stays a small, readable bytecode VM with a template-JIT heritage, rather than a tracing JIT with SSA-style IR. The optimizer folds constants, eliminates dead code, and specializes a handful of hot patterns (s = s + i, i = i + 1) into superinstructions, keeping the whole kernel in one C file.
