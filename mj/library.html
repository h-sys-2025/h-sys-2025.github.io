stdlib/ + vendor-libs/

Library

What ships with mj: a small standard library written partly in C and partly in mj itself, plus a bundled vendor registry of 23 small packages.

Standard library (stdlib/)

ModuleFileRole

externstdlib/extern/natives_table.inc / natives_body.inc, the plumbing for registering new natives
extern_cstdlib/extern_c/C / C++ / Odin interop shims and mj_api.h, the embedding ABI

The two new demo scripts that exercise these, examples/demo_net.mj and examples/demo_radix.mj, currently load them from a path that does not exist in the repository. Use stdlib/extern_c/net_sockets.c and stdlib/extern_c/radix_utils.c as the native ... from path instead.

Every package folder carries a lib.mj and an mjpkg.toml manifest. Add one with ./mjpm.sh add <name>.

Builtin methods, quick reference

UFCS-style: value.method(args), working on strings, arrays, maps, ints, and f64. Full lists are on the Docs page.

CategoryA few of the methods

Mapsget, set, has, keys, values, delete
Numbersabs, floor, ceil, sqrt, clamp, is_even, to_string
Universaltype, to_string, len
